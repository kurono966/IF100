# 世界に5回だけ触れる

TypeScript + Vite + Phaser 4 のローカル完結MVP。実行時に外部API、AI、CDNへの接続はありません。

## 起動

```sh
npm install
npm run dev
```

表示されたlocalhostのURLをブラウザで開きます。スマートフォンでは同じWi-Fi上からPCのIPアドレスと表示ポートを指定します。

```sh
npm test
npm run build
```

`dist/` が配信可能な静的ファイルです。ファイルを直接開くのではなくHTTPサーバーで配信してください。

## 遊び方

タイトル画面で任意の整数シードを指定できます。開始時は一時停止。再生すると100年まで自動進行します。介入を選ぶと一時停止するので、対象タイルを選び、再生を再開してください。道路は始点と終点を選び、横→縦の経路で接続します。川を通す道路には橋が必要です。失敗した指定は回数を消費しません。介入なしでも最後まで観察できます。

100年後に非公開だったBaselineと比較できます。差分モードでは地形利用、都市段階、森林、道路、建物の異なるタイルを橙で囲みます。数値だけの差は比較表に表示します。因果チェーンは実際に生成されたイベントの親IDをたどります。JSON保存には両世界の全状態と介入記録を含みます。

## 構成

- WorldState: 世界・地域・介入・履歴の型
- SeededRandom: seed / 用途 / 年 / 地域による独立した決定論的乱数
- WorldGenerator: 初期地形と集落
- Simulation: 1年更新、全期間再生、集計、分類
- Intervention: 適用条件、道路経路、地域への持続的作用
- EventHistory: 親ID付き履歴と最長の因果経路
- Renderer: Phaser製タイル地図（図形のみ、外部素材なし）
- main: HTML UIと時間進行

`simulate(seed, interventions)`で任意の履歴を再生可能。介入年は年更新の直前の状態を意味します（例：18年の介入は18→19年の更新から作用）。不正な介入は例外になります。同一年は配列順に適用します。

経済は簡略モデルです。因果履歴は交通・開発の依存関係を記録するもので、各イベントの全要因を証明するものではありません。鉄道・政治・音楽・オンライン保存は対象外です。
