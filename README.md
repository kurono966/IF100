# 世界に5回だけ触れる — 小さな自然の異常

TypeScript + Vite + Phaser 4 のローカル完結MVP。実行時は外部API・AI・CDNを使用しません。

```sh
npm install
npm run dev
```

表示URLをブラウザで開きます。同じWi-FiのスマートフォンではPCのLAN IPとポートを使用します。

```sh
npm test
npm run build
```

成果物は `dist/`。HTTPサーバーで配信してください。

## 遊び方

シードを指定して開始。再生・停止・×1/×3/×10で100年間を観察します。自然介入を選ぶと一時停止します。陸地を1回タップして異常を起こし、再生を再開してください。失敗した指定は回数を消費しません。施設を作る操作はありません。

- 雨：半径2マス、次の4回の年更新だけ雨量を増加
- 干ばつ：同範囲・同期間だけ雨量を減少
- 落雷：1マスの植生と森林を一部焼き、灰で土壌が肥沃になる
- 植物：1マスの植生と生物多様性を少量増加
- 草食動物：1マスに8個体を一度だけ導入
- 捕食動物：1マスに3個体を一度だけ導入

導入後は毎年の自然な増減・移動に従います。雨・干ばつ終了後も、水や植生に残った変化は徐々に推移します。介入は人口、経済、技術、開発、道路を直接変更しません。道路や都市は文明の自動発展としてのみ現れます。任意の地域を選ぶと雨・気温・土壌・植生・水・動物・食料を観測できます。

## モデル

毎年、全地域について各段階を完了してから次へ進みます。同一段階の移動・伝播には前年のスナップショットを使い、走査順に依存しません。

1. 天候：用途別の決定論的乱数、4年間の局地異常、河川、水分
2. 植生：水、土壌、種子の伝播、被食、火災、森林と草地の安定性
3. 生物：植物による草食動物の収容力、捕食、隣接地域への移動
4. 食料：開けた土地の農業適性、植物・草食動物由来の食料、捕食圧
5. 人口：食料に基づく収容力と増減、隣接人口からの移住
6. 文明：人口・食料余剰から交易、経済、開発、技術、集落・都市へ

森林は生息地を増やす一方、農業に使える土地を減らします。植生は密度によって回復速度が変わるため、小さな攪乱で草地と森林の長期的な姿が変わることがあります。リアルな自然史の再現ではなく、局所的な食物連鎖と文明への波及を観察する簡略モデルです。全ての介入が大きな変化を起こすとは限りません。

## 比較と因果履歴

開始時にBaselineを最後まで計算し、終了まで非表示にします。100年後は左右地図、数値比較、植生・動物・都市・道路の差分表示、世界分類、JSON保存を利用できます。

イベントは実際の計算上の依存関係を親IDとして記録します。最大5つの介入の起源を維持しながら親を圧縮し、100年後に差が大きい地域へ至る代表経路を抽出します。表示は各段階を抜粋し、各イベントに地域とBaselineと同年・同地域・同名の経過かを表示します。終点にはその地域の人口・森林率を左右比較します。

これは依存関係の説明です。共通する経過も含み、各イベントがその介入だけで発生したという反実仮想の証明ではありません。複数の介入や自然変動が組み合わさることがあります。介入直後に100年を迎える場合、長い因果経路が生じないこともあります。

## 再現例

Seed `418275`、0年に植物を `(4,9)`、`(10,13)`、`(3,5)`、`(8,3)`、`(1,12)` へ導入。同じシードの無介入世界と比較すると、これらの地域の森林率に約64〜87ポイントの差が生まれ、人口が増える地域と減る地域が両方現れます。固定のイベント演出ではなく通常のシミュレーション結果です。

## 責務

- `WorldState`: 世界・地域の自然/文明パラメータ、期限付き効果、履歴の型
- `SeededRandom`: seed / 用途 / 年 / 地域から算出する乱数
- `WorldGenerator`: 地形と自然系・文明系の初期値
- `Simulation`: 天候→植生→生物→食料→人口→文明、集計、分類
- `Intervention`: 6種類の検証と自然パラメータへの適用
- `EventHistory`: 親IDと起源の記録、代表経路抽出
- `Renderer`: Phaser製地図、植生・動物・火災・期限付き異常の表示
- `main`: HTML UIと進行制御

`simulate(seed, interventions)`で100年を再計算できます。年18の介入は18→19年の更新から作用し、同年は配列順に適用します。最大5回、不正な地域・年・重複ID・廃止済みの介入種は拒否します。
