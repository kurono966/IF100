# 世界に5回だけ触れる — 1000年の文明と、その痕跡

TypeScript / Vite / Phaser 4。実行時の外部API・LLM・画像素材への依存はありません。自然の異常と普通の移住者の到着を、合わせて最大5回だけ起こし、文明の千年を観測します。

## 起動

```sh
npm install
npm run dev
```

表示されたURLをPCブラウザで開きます。スマートフォンは同じネットワークからPCのLAN IPとポートへアクセスします。

```sh
npm test
npm run build
```

`dist/` が静的配信の成果物です。Web Workerを使用するため、HTMLをファイルとして直接開かずHTTPサーバーで配信してください。外部サーバーや外部アカウントは不要です。

## 遊び方と千年の時間

開始時に同じシードのBaselineを1000年まで裏で計算します。準備はWeb Workerで実行し、結果は終了まで非公開。準備完了後に再生してください。

- ×1 / ×10 / ×50 / ×100。内部の基準は×1で約300msに1年です。
- 100年ごとの目盛りと時代名を表示。
- 「重要な変化でスロー」が有効な場合、重要イベントで約0.85秒停止して強調。25年以内の連続通知はまとめます。
- 介入の選択で一時停止。自然現象または移住者を選び、地図の対象地域をタップしてから再生を再開。
- 年代スライダー、世紀の目盛り、重要イベント一覧から、観測済みの年代へ移動可能。
- 過去は閲覧専用。介入や再生には「現在へ戻る」を使用します。閲覧で現在の世界は変わりません。
- 1000年後は左右地図、差分、数値、各介入の最大・最長の因果経路を比較できます。「重要年代を振り返る」で終了後も観察可能。

通常の変化を逐一文章化せず、集落・市場・技術・文明の転換や災害を優先表示します。重要年の候補は最近だけに偏らないよう各世紀から選びます。

## 介入

雨・干ばつは半径2マスに4年間だけ小さな雨量変化。落雷と山火事は1マスの火種。植物・草食動物・捕食動物は少量を一度だけ導入します。川の増水は2年間、気温上昇は3年間で1.5℃、強風は1年間。自然介入は人口、健康、経済、技術、市場、道路を直接変更しません。

移住者だけは、本人と0〜4人の同行家族が到着するため、その人数を地域人口に加えます。それ以上の即時の人口・技術・経済ボーナスはありません。家族を含む到着人数もプロフィールに記録します。自然介入と共通の5回の枠を消費します。

移住者には名前・年齢・職業・技能・知識・性格・出身文化・家族構成・健康・持ち物・移住理由があります。名前、年齢、職業、同行家族を変更できます。職業は陶工、小舟建造、耕作、薬草、鍛冶、交易に対応します。

初期世界にも普通の働き手が存在し、移住者と同じ加齢・死亡・学習規則で活動します。人物は寿命があり、不死の英雄にはなりません。技能の定着には、現地の資源、一定の人口、健康、練習年数が必要です。

## 時代による変化

### 0〜100年：自然と定住

天候、植生、植物→草食→捕食、移住、小集落。働き手から家族・弟子へ技能が伝わります。

### 100〜300年：文化と交易

人口400人以上、食料余剰、周辺に2つ以上の集落がある状態の継続で市場成立。100年以降に交易網、120年以降に道路、技能が長く実践されると地域文化、150年以降は条件が整えば地域産業へ。

### 300〜600年：都市と文明圏

市場、交易、人口流入、開発がそろうと都市化。共通の文化や交易で結ばれた複数都市が十分な人口を持つと文明圏が成立。地域ごとの独自習慣、技術体系、中心都市の競争が起こります。

### 600〜1000年：継承と再編

人口と産業による資源消耗、都市の維持負担、災害、疫病、交易先の変化は、都市や文明圏を衰退・崩壊させ得ます。低密度の地域では資源や土壌が回復し、旧集落の遺構を使った再興が可能です。衰退や再興は指定年の固定シナリオではなく、蓄積した負担や生活条件の閾値で決まります。

成長し続ける設計ではありません。技術も人口の減少に伴って失われることがあります。交易路は利用が途絶えると実効性を失い、新しい交易中心が形成されます。

## 人がいなくなった後

家族と弟子は個人を無制限に生成するのではなく、世帯数・弟子数・25年単位の世代として簡略化しています。継承される技術は現地の資源と実践に依存し、放棄された地域では衰えます。移住者本人の死後も、技術・地域文化・産業は存続し、交易路や近隣の交流を経て他文化へ伝わる可能性があります。

伝統には起点地域、開始年、技能の起源となる介入ID、世代、強さ、家族・弟子、直近の原因イベントを保持します。遺構・地名・技術利用の記録は、都市が失われても痕跡として保存します。

陶器の保存技術、小舟や商業の交易効率、耕作、薬草、地域産業は小さな実利を持ちます。人物を追加した直後に文明を作るのではなく、技能が定着した後に日々の生活へ作用します。

## 再現例

Seed `418275`。23年に `(10,2)` へ初期プロフィールの陶工を追加します。既定プロフィールのスイは34歳で到着し、63年に74歳で死亡します。その後も技能が別地域へ広がり、1000年時点で最大40世代の継承が確認できます。

同じシードでも無介入世界と、人口・都市・文化・交易の歴史が分岐します。人物本人が生き続けて起こす変化ではありません。固定された専用ストーリーもありません。介入の場所や年により、技能が定着しない、余波が小さい結果もあります。

## 因果と比較

`EventHistory` の親IDをたどり、各介入から1000年までの最大変化の経路と、最も長い経路を抽出します。数百件の経路は各世紀の重要な転換を最大14件に抜粋。比較対象の同じ地域がBaselineでどう推移したかも並べ、他地域に残った技能や文化の世代数を表示します。元の全履歴はJSONで保存できます。

親IDはモデル内の計算上の依存関係です。共通する経過や複数の要因も含み、各イベントが1つの介入だけで起きたことを証明するものではありません。結果は勝敗や優劣として評価しません。

## 性能と再現性

- 年更新は決定論的。乱数はシード・用途・年・地域から個別に計算し、呼び出し順で別用途の結果を変えません。
- Baselineは専用Worker。ライブ進行はフレームごとの計算時間を区切り、複数年進んでも描画はまとめます。
- 生態・天候は1年刻み。100年以降の移住判定は3年、文化の実践は5年、伝播と交易路候補は10年/5年、文明圏は25年間隔で処理。
- 毎年の状態コピーは履歴全体を複製せず、更新に必要な地域だけ。
- 過去の閲覧は25年ごとのチェックポイントと、最大24年の再計算で復元。チェックポイントは共有の履歴本体を重複保存しません。
- 因果の親IDは最大5介入の起源と背景を保持し、1イベント当たり最大6つに圧縮。

## コード構成

- `HistoryConfig`：終了年・世紀・時代
- `WorldState` / `WorldGenerator` / `SeededRandom`：型、初期世界、乱数
- `Simulation`：年間処理と集計
- `NatureSystem` / `LifeSystem` / `SocietySystem`：自然、生活、人口と移住
- `CivilizationSystem`：市場、道路、都市、交易
- `CultureSystem`：人物、プロフィール、寿命、家族・弟子、技能、文化伝播
- `LongHistorySystem`：都市の負担、盛衰、文明圏、再編と遺構
- `Intervention`：共通の介入枠と検証
- `EventHistory` / `InterventionChronicle`：原因ID、最大/最長経路、比較
- `SimulationArchive`：過去の復元。`baseline.worker`：Baseline計算
- `Renderer` / `main`：コード描画とレスポンシブUI

`simulate(seed, interventions)` は1000年を返します。第3引数で0〜1000年の部分計算も可能です。年18の介入は18→19年から作用し、同年は配列順。1000年目で介入は終了します。
