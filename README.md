# IF100 — 谷の人々

40人・2集落・8×8の小さな谷で、人物の人生と世代交代を200年間観察する社会シミュレーションMVPです。プレイヤーの小さな介入が、その人の学び、仕事、人間関係、子供や教え子へと波及します。実行時のLLM・外部API・ネットワーク通信はありません。

## 起動と検証

```sh
npm install
npm run dev
npm test
npm run build
```

Viteが表示するURLを開いてください。`dist/`は静的配信可能です。新しいゲームは`index.html` → `src/SocialApp.ts`から起動します。

## 遊び方

- 左側の地図の点、または中央の住民一覧から人物を選びます。
- 右側で性格、技能、家族、現在の目標、所有物、人生の記録を確認します。
- 「この人生に触れる」で知識、道具、学習機会、出会い、移住、療養、新しい一家の移住を導きます。知識は未習得のものを選んでください。
- `+1年`、`+10年`、または自動進行で時間を進めます。200年で停止します。
- 家系・関係・知識伝播・因果タブで、人物や出来事のつながりをたどれます。故人は住民一覧の「故人も表示」から選べます。
- 「介入からの波及」で起点を選ぶと、その介入につながる出来事を表示します。「因果をたどる」は選択した出来事の親イベントをさかのぼります。
- 保存・読込でJSONとして歴史全体を持ち運べます。生存者だけでなく故人と家系・人生履歴も保持します。

## モデル

`SocialTypes.ts`の`SocialWorld`が新しい世界状態です。`PersonSimulation.ts`が生成・年更新・人物介入を担当します。

全住民は固有IDを持つ`Person`です。人口、職業人数、家族数はPersonから算出し、セル人口はその投影です。旧来のセル人口増殖や文明成長システムは、新ゲームから呼び出しません。初期40人は10組の夫婦と各2人の子供で、故人を含む全員を永続的に保持します。生存人口は95人までに制限します。

性格は職業評価、労働量、対人交流、探索・移住、学習、対立、知識・価値観の受容などに影響します。技能は仕事、親の教育、他人からの学習で成長します。目標候補を性格・年齢・家庭・資産・社会状況から評価し、学習、育児、探索、貯蓄、家族形成に反映します。

集落の食料は実在する農民・狩人・採集者の生産の合計です。食料不足は職業評価と健康に影響し、余剰は出生や専門職の存続を支えます。大工が住居を作り、商人と職人が余剰のある集落で定期市を形成します。知識は人物が保持し、交流・教育で伝わります。セルに技術を直接付与しません。

家族形成は成人同士の好意、生活状態、近親関係を確認します。出生では親の性格、seedに基づく変異、家庭の協力観を反映し、親子リンクで何世代でも追跡できます。師弟・友人・ライバルなどの関係は接触した組だけ保持します。

## 決定論と因果の範囲

既存の`SeededRandom.value(seed, stream, year, personId)`を使います。`Math.random`は使用しません。同じseed・同じ年・同じ順序と対象の介入で同じ世界になります。JSON保存後の再開も同じ未来になります。

既存`EventHistory.record`を再利用し、出来事の`parents`と介入の`roots`を保持します。知識伝播は元の習得イベント、職業変更は関連知識、技能教育は教える人物、出生は親の影響履歴を参照します。介入で紹介された相手との再交流も、面識に応じた接触確率に反映します。

食卓支援の記録は、介入につながる労働者の生産を差し引くと当年の需要を満たせない場合に作ります。これは実際の処理依存を追う履歴であり、別世界との厳密な反実仮想比較ではありません。因果タブの矢印はイベントID間の参照を表します。

## MVPとしての制約

地図は固定形状の谷で、seedは住民と地勢の一部に影響します。職業・食料・健康・家族は簡略モデルです。災害の生成と専用の救出タイミングは未実装で、救助介入は個人の健康回復として機能します。ネットワーク表示はクリック可能な家族階層・関係一覧・因果リンク付き履歴です。自由配置のグラフ表示は今後の拡張範囲です。

旧文明版のコードは地形生成の再利用と回帰検証のため残しています。旧画面・旧シミュレーションは現在のエントリーポイントでは動作しません。旧仕様の資料は`LEGACY_README.md`に退避しています。

`tests/people.test.ts`は初期住民、親子整合性、複数seedの200年進行、決定論、出生・結婚・死亡・移住、因果DAG、100年後への波及、保存復元後の一致を検証します。
